## 4. 字段对齐设计（2026-11-18）

```text
源字段视图（类型/空值率/基数）
   × 目标 schema（8 个源字段，按事件类型限定允许源表）
   → name / type / structure / value 四个匹配器
   → 加权组合（0.45/0.25/0.15/0.15）
   → top-3 + 阈值 0.5 + 类型过滤（允许 1:N）
   → field_level.csv（auto/review + evidence）
   → alignment_report.json（覆盖/必填/复核）
```

- 目标字段：`subject_id`、`hadm_id`、`stay_id`、`event_time`、`code`、`display`、
  `numeric_value`、`text_value`；`record_id`、`event_type`、`split` 等是派生字段，不匹配；
- 目标 schema：`governance/alignment/target_schema.yaml`；
- MEDS 交叉表：`field_level_meds.csv`（9×5，接口对照，不是匹配结果）；
- 派生/聚合：`derived_fields.csv`，例如 `n_admissions`、`total_los_days`、`top_drug`；
- 不再有 `_field_map()`、33 条 gold、`field_level_reference.csv`、`LEGACY.md`。

1. `standardize.py` 的 MEDS 映射仍是硬编码，未由 matcher 生成；
