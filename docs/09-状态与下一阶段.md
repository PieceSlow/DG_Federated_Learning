## 6. 新框架（P1-1d，下一步）

```text
源字段（MIMIC 原始列） × 目标字段（MEDS 接口，按事件类型）
   ├─ NameMatcherAgent
   ├─ TypeMatcherAgent
   ├─ StructureMatcherAgent（事件类型/表角色/主外键）
   ├─ StatsMatcherAgent（空值率/基数，无原始值）
   └─ SemanticMatcherAgent（LLM，可选）
        ▼
   相似度矩阵 → 组合器（权重 + 一致性）
        ▼
   约束执行器（1:1 / 1:N / 类型 / 必填）
        ▼
   匹配选择器（粗筛 → 精排 → 定结果）
        ▼
   MEDS 事件表 → schema 校验
```

验收：

1. 每个 matcher 是 Agent，写 trace，输出统一矩阵；
2. 组合器权重可配，输出一致性；
3. 约束执行器能拒绝非法/冲突映射；
4. 选择器输出 MEDS 字段覆盖率；
5. 5–10 人小批量 `--llm off/mock/api` 跑通，API 预算 ≤20 元；
6. 不再引用 33 条 gold / `patient_360`。
