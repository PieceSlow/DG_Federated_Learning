# 05 · 对象化与标签化

## 1. 对象化：从"表"到"对象"

对象化的价值是给数据一个**业务语义的骨架**：谁是谁、谁属于谁、以什么键关联。有了这层骨架，
编目、共享、联邦建模才有共同语言。

### 1.1 7 类对象

| 对象 | 主键 | 粒度 | 敏感级别 | 行数（本队列） |
|---|---|---|---|---|
| Patient | `subject_id` | 1 行/患者 | L3 | 100 |
| Encounter | `hadm_id` | 1 行/住院 | L3 | 350 |
| ICUStay | `stay_id` | 1 行/ICU 停留 | L3 | 126 |
| ClinicalNote | `note_id` | 1 行/出院小结 | L3 | 155 |
| Diagnosis | `subject_id + hadm_id + seq_num` | 1 行/诊断 | L2 | 5,319 |
| Prescription | `subject_id + hadm_id + pharmacy_id` | 1 行/处方 | L2 | 18,384 |
| Procedure | `subject_id + hadm_id + seq_num` | 1 行/操作 | L2 | 696 |

### 1.2 6 条关系

```text
Patient ─1:N─ Encounter ─1:N─ ICUStay
                  ├─1:N─ ClinicalNote
                  ├─1:N─ Diagnosis
                  ├─1:N─ Prescription
                  └─1:N─ Procedure
```

### 1.3 产物

- `output/governance/metadata/object_graph.json`：对象、键、属性、行数、关系；
- `output/governance/metadata/object_inventory.csv`：扁平的清单，便于放进表格或报告。

对象图里**只有结构与计数，没有患者行**，因此定级 L1，可以公开引用。

## 2. 标签化：给数据建立语义层

标签不是"多算几个字段"，而是让数据可检索、可分级、可共享。本项目定义 5 个维度：

| 维度 | 取值 | 用途 |
|---|---|---|
| `event_type` | Diagnosis / Procedure / Prescription / ClinicalNote | 对象类别 |
| `code_system` | ICD9 / ICD10 / MIMIC_FORMULARY / MIMIC_NOTE | 术语体系 |
| `icd_chapter` | ICD 章节（21 类）+ `N/A` + `Unknown` + `Other / unclassified` | 粗粒度病种画像 |
| `sensitivity` | L1 / L2 / L3 | 分级与共享边界 |
| `split` | train / tuning / held_out | 联邦训练防泄漏 |

标签清单落成 `output/governance/metadata/labels.json`，包含每个维度的定义、级别与取值分布。
它的用途是：拿到一个数据集，先看标签清单就知道"里面有什么、能不能给、怎么用"。

### 2.1 ICD 章节映射

ICD-10 按首字母归章（A/B 传染病、C/D 肿瘤、I 循环、J 呼吸……），`H` 段特殊处理：
`H00–H59` 归眼科、`H60–H95` 归耳科。ICD-9 按数字区间归章（1–139 传染病……800–999 损伤）。
无法识别时给 `Unknown`（空编码）或 `Other / unclassified`（未知段），不留空串——
空串在后续统计里会被误当成缺失值。

### 2.2 敏感级别与对象类型

| 对象类型 | 级别 | 依据 |
|---|---|---|
| 诊断 / 操作 / 处方 | L2 | 健康状态敏感，但结构化、已编码 |
| 临床文本 | L3 | 自由文本含叙述性隐私，可推断身份与事件 |
| 人口学 / 就诊 | L3 | 年龄+性别+时间轴可辅助重识别 |

同一患者在不同表里可能被标成不同级别（例如人口学 L3、诊断 L2），因此**行级敏感级别取该行所属对象的级别**，
患者 360 则取最高级别 L3。这条规则写死在 `assemble` 里，避免各处自行判断。

## 3. 与分类分级的关系

标签化负责"打上语义与级别"，分类分级负责"把它变成制度"：每类数据怎么用、谁能看、
去标识到什么程度、能共享到什么边界。详见 `06-分类分级与编目.md`。

## 4. 局限

- ICD 章节只是粗粒度语义，不能替代临床分类（如 DRG）；
- 没有 SNOMED/LOINC 等更细的术语标签；
- 文本没有做 PHI 重识别风险评估，因此整体按 L3 处理。
