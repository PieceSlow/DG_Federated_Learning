## 4. 口径说明

| 项 | 当前口径 |
|---|---|
| 对齐目标 | 8 个由源字段直接提供的对象字段（`target_schema.yaml`） |
| 对齐方法 | name/type/structure/value 四匹配器 + 加权组合 + **每个「目标字段 × 源表」top-3** + 声明字段直接准入 |
| 对齐结果 | `field_level.csv` 带 `status=auto/review`、`method=matcher/declared`、`score`、`evidence` |
| 评估 | 覆盖率 + 必填覆盖 + review 数；没有 gold P/R |
| SQL 消费 | `build_clinical_events.sql` 的表达式来自映射；`mapping_usage` 给出 mapping/transform/spec/derived/link/postprocess/missing 计数，并与事件表逐列对账 |
| 聚合字段 | `derived_fields.csv`（n_*、total_los_days、top_* 等），不参与匹配 |
| MEDS 接口 | `meds_targets.yaml` 是唯一声明；`field_level_meds.csv` 10×5 台账回填了匹配结果，`resolved_by` 区分 mapping/spec/derived/none/unmapped |
