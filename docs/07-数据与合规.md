# 07 · 数据与合规

## 1. 适用许可

| 数据 | 许可 | 对本项目的约束 |
|---|---|---|
| MIMIC-IV v3.1 | PhysioNet Credentialed Health Data License v1.5.0 | 仅限获授权的个人在受控环境使用；不得再分发原始或可还原的行级数据 |
| MIMIC-IV-Note 2.2 | 同上（Credentialed） | 出院小结原文属高敏感文本，不得外传、不得放入公开材料 |
| MEDS schema | Apache-2.0 | 可随代码分发，保留许可与声明 |

一句话原则：**代码可以公开，数据不行；汇总统计可以写进报告，行级记录不行。**

## 2. 分级与处置

| 级别 | 内容 | 允许的去向 |
|---|---|---|
| L1 | 数据字典、对象图谱、聚合统计（k ≥ 10） | 可写进报告/PPT、可进公开仓库的 `docs/` |
| L2 | 诊断、操作、处方等结构化事件（仍带 `subject_id`） | 仅本地；对外只给聚合或去标识后的受控共享 |
| L3 | 人口学、就诊时间、临床文本原文 | 仅本地受控环境；不共享、不展示原文 |

`output/` 里的 parquet、`issues.csv`、`audit_log.csv` 都属于 L2/L3，
因为里面有 `subject_id`、`hadm_id`、`note_id` 或文本原文。

## 3. 仓库红线

以下内容**一律不得提交**（`.gitignore` 已排除，但不要只依赖它）：

- `output/**`：全部运行产物（事件仓储、治理资产、审计）；
- 任何 `*.parquet`、`*.csv`、`*.csv.gz`、`.zip` 数据包；
- 报告/PPT 里的患者级示例（患者号、住院号、小结原文片段）；
- 指向本机数据目录的截图（`F:\mimic-iv数据\...` 的路径截图也建议打码）。

## 4. 提交前检查

```powershell
git status --short                               # 有没有意外的数据文件被暂存
python scripts/check_no_patient_data.py          # 启发式扫描（数据文件 + 8 位 ID）
git diff --cached --stat                         # 再看一眼 diff
```

`scripts/check_no_patient_data.py` 按扩展名拦截数据文件，并按正则找 8 位数字（MIMIC 的
`subject_id`/`hadm_id` 量级）。它是**启发式**检查：会误报（例如引用文献编号），但不会漏掉明显的
行级数据。发现报错请删掉对应内容，而不是加白名单绕过。

## 5. 报告与 PPT 的脱敏写法

| 不要这样写 | 建议写法 |
|---|---|
| 患者 XXXXXXXX，男，65 岁，因胸痛入院…… | "队列中一名 65 岁男性患者"或"以一位患者为例（示例已改写）" |
| 截图里带 `subject_id` 列 | 截图前隐藏 ID 列，或只截聚合统计 |
| 贴出院小结原句 | 只写"出院小结中的既往史章节"这类描述 |

只要写进报告的材料，都按"会被公开传阅"来准备。

## 6. 万一误提交

1. **先不要 push**；如果已经 push，立刻联系仓库管理员。
2. 用 `git rm --cached <文件>` 从索引移除，但注意**历史里仍有**。
3. 需要彻底清除历史时用 `git filter-repo --path <文件> --invert-paths`，然后强制推送，
   并通知所有协作者重新克隆。
4. 若已推送到公开平台，按 PhysioNet 的要求上报并说明处理过程。

## 7. 联邦场景下的共享边界

五级目录已经把边界写清楚，落地时按此执行：

- **不出本地**：L3 原文、人口学明细、行级事件表；
- **可受控共享**：去标识后的 L2 事件表，需数据使用协议 + 伦理审批；
- **可开放**：数据字典、对象图谱、分级规则、k ≥ 10 的统计汇总。

联邦学习只交换模型参数或梯度，但参数仍可能泄漏训练数据，因此模型发布前需做成员推断/记忆化
风险评估——这超出本仓库范围，但应在方案里写明。
